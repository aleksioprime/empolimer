# Установка станции на Raspberry Pi

Установка выполняется **с компьютера по сети**: скрипт копирует [rpi/](../rpi/)
на плату и настраивает её. Нужны `bash`, `ssh` и `rsync` (macOS, Linux; на
Windows — WSL). На плате — Raspberry Pi OS Bookworm с рабочим столом,
включённый SSH.

## 1. Доступ по SSH — один раз

```bash
ssh-copy-id pi@192.168.1.50
```

Без ключа пароль спрашивается один раз за запуск. Пароль `sudo` на плате
спрашивается для установки пакетов.

## 2. Установка

```bash
deploy/install.sh pi@192.168.1.50 --autostart
```

Установщик:

1. копирует программу в `~/empolimer` (файл `station.conf` на плате не трогает);
2. ставит из apt `python3-pyqt5`, `python3-serial`, `python3-picamera2`, `python3-qrcode`
   (с `--usb-camera` — ещё `python3-opencv`), только если их нет;
3. добавляет пользователя в группы `dialout` (порт ESP) и `video` (камера) —
   после этого попросит перезагрузить плату;
4. создаёт `~/empolimer/station.conf` из примера;
5. кладёт на рабочий стол ярлык «Станция ЕмПолимер», с `--autostart` —
   включает запуск при входе в рабочий стол.

| Параметр | Что делает |
| --- | --- |
| `--autostart` / `--no-autostart` | включить / убрать автозапуск |
| `--usb-camera` | поставить OpenCV для USB-камеры (на Pi Zero — долго) |
| `--code-only` | только обновить код, без apt и групп — быстро |
| `--dest DIR` | каталог на плате вместо `~/empolimer` |
| `--port N` | порт SSH |
| `--dry-run` | показать команды, ничего не выполняя |

## Обновление

```bash
deploy/install.sh pi@192.168.1.50 --code-only
```

Если станция запущена, установщик перезапустит её с новым кодом.

## Проверка на плате

```bash
ls /dev/ttyUSB* /dev/ttyACM*      # ESP видна?
rpicam-hello --list-cameras       # модуль камеры виден?
tail -f ~/empolimer/station.log   # журнал станции при запуске ярлыком
```
